# NOLUNE (Music Listening Lounge)

## ① 課題名

NOLUNE (Music Listening Lounge)

## ② 課題内容

架空の音楽リスニングラウンジ「NOLUNE」のランディングページを制作しました。

広告や通知に邪魔されず、アルバムを最初から最後までゆっくり楽しめる場所をイメージしています。

- PW：なし

## ⑤ 工夫した点・こだわった点

文字の大きさや余白、細い線の使い方を工夫し、音楽雑誌のようなデザインを目指しました。

また、サービス紹介のセクションでは、画像と文章を左右交互に配置することで、ページ全体が単調にならないようにしました。

各セクションに移動できるよう、上部のナビゲーションにもリンクを設定し、ページを見やすくしました。

## ⑥ 難しかった点・次回トライしたいこと（又は機能）

HTMLとCSSを使って、自分がイメージしていたデザインに近づけることが難しかったです。特に、画像の大きさや余白の調整に時間がかかりました。

CSSの数値を少し変えるだけでも、ページ全体の見た目が大きく変わることを学びました。

また、AIを使って調べながら制作しましたが、まだ理解できていないコードもあるので、これから少しずつ理解を深めていきたいです。

次回はスマートフォンでも見やすいデザインに対応させることと、地図を動かして操作できる機能の実装にも挑戦してみたいです。

## ⑦ フリー項目（感想、シェアしたいこと等なんでも）

自分で考えたアイデアを実際にWebサイトとして形にすることができて、とても面白かったです。

最初は思い通りに配置できないこともありましたが、何度も調整を重ねることで、少しずつ完成に近づけることができました。

まだ勉強が必要な部分も多いので、これからはコードを動かすだけでなく、一つひとつの意味や仕組みも理解しながら、自分の力でWebサイトを作れるようになりたいです。
